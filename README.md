# mimi ♡

高校生向けの健康習慣記録Webアプリ。食事・活動・睡眠・体調などを端末内で記録します。

## 公開設定 (Netlify)
- Production branch: `main`
- Build command: なし
- Publish directory: `.` (リポジトリのルート)
- サイトURL: https://lovely-gnome-0cdde2.netlify.app/

## プライバシー
利用者の実際の記録・バックアップ・個人情報をGitHubへコミットしないでください。
localStorageに記録するためブラウザーのデータ削除で消える場合があります。
